VoidOS 2.0.3, before and after

Screens, 2.0.2 against 2.0.3, landscape and portrait

Saved Nov 21, 2026, 3:55am

Each drawer now has one way to show where you are, and six other duplicate controls are gone.

DrawersHomeAlarmsNotesSettingsCalendarDev Apps

Metrics drawer

The screen you're on was marked twice, with a teal dot and a brighter row. Now it's just the dot.

Apps drawer

Same single marker as the left drawer.

Home widgets

The Done button in the widget menu is gone. The edit tick is the one way out.

Alarms

With no alarms, the big Add alarm button is gone. The + in the header adds one.

Notes

The separate Sketch button is gone. Start a note, then tap Draw.

Settings, VoidOS

The tablet name saves as you type, so its Save button is gone. The second Screen off after control is gone too: Settings, Screen keeps the one.

Calendar

No duplicate controls found. Shown so you can check it.

Dev Apps

No duplicate controls found. Shown so you can check it.
